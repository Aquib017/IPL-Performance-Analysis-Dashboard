# IPL-Performance-Analysis-Dashboard


## Project Overview

An interactive **IPL Performance Analysis Dashboard** developed using **Power BI** to analyze team, player, match, and tournament performance.

## Key Features

* Team-wise and season-wise performance analysis
* Player batting and bowling performance
* Top batsmen and bowlers analysis
* Toss decision and match outcome analysis
* Venue-wise match analysis
* Interactive season and player filters
* KPI cards for key performance metrics

## Tools & Technologies

* **Power BI**
* **Power Query**
* **DAX**
* **Data Visualization**
* **Dashboard Development**

## Key Insights

* Identified top-performing batsmen and bowlers
* Compared team performance across seasons
* Analyzed toss decisions and their impact on match results
* Examined venue-wise and season-wise performance trends

## Dashboard

The dashboard provides an interactive view of IPL performance metrics and enables users to explore the data using filters and visualizations.

## Skills Demonstrated

**Data Cleaning | Data Analysis | KPI Reporting | Data Visualization | Power BI | Dashboard Development**
